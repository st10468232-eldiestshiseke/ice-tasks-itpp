Professional Reflection

What this module taught me, where I am strong, and what I want to improve next.

What I Have Learned During This Module

This module taught me that a professional online presence does not happen by accident — it is planned, designed and maintained. While building this portfolio I learned how to structure a multi-page website with consistent navigation, apply a cohesive visual identity through fonts, colours and spacing, and use responsive design so that every page works well on both desktop and mobile devices. I also learned the basics of search engine optimisation: meaningful page titles, descriptive headings, alt text for images and descriptive link text. These practices help search engines — and potential employers — understand who I am and what I can do. Finally, connecting this portfolio to my GitHub and LinkedIn profiles taught me to keep my professional identity consistent across every platform I use.

My Strongest IT Professional Skill

My strongest skill at the moment is translating a client's requirements into working software. My React Native menu-management application for a private chef is a good example: from a simple brief, I built a cross-platform app in which the chef can add and remove menu items, see the total number of items and the average price per course, and present guests with a menu they can filter by course. Watching a real user's problem become a working, tested app is the part of IT I enjoy most.

The Skill I Would Like to Improve

The skill I would most like to improve is responsive web development, particularly writing my own JavaScript for interactivity rather than relying only on what I already know. My mobile-development experience is currently stronger than my web-development experience, and this portfolio is my first hand-built website.

How I Will Develop That Skill

To close that gap I will practise deliberately. I plan to work through free, structured resources such as MDN Web Docs and freeCodeCamp, rebuild small personal projects as websites instead of apps, and study websites I admire to understand how their layouts respond to different screen sizes. I will also keep updating this portfolio as I learn, so improving the skill and showcasing it become the same habit.

How This Portfolio Supports My Future

In the short term, this portfolio gives my lecturers, peers and future employers a single link that shows my best work. In the longer term, it will support my applications for internships and graduate programmes: instead of only listing skills on a CV, I can show evidence of them. Because I can update it throughout my studies, the portfolio will also become a record of my growth — a way to see, project by project, how far I have come as an aspiring software developer.
