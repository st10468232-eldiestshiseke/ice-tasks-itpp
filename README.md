# Eldies Tshiseke — Professional Digital Portfolio

A responsive, multi-page portfolio website that introduces me as an aspiring software developer and IT student. It showcases my projects, professional profiles, and my growth throughout my studies, and it is deployed with GitHub Pages.

**Live site:** [https://github.com/st10468232-eldiestshiseke)

> **Note:** Replace the links in this README with your own GitHub Pages URL, GitHub profile, LinkedIn profile, and email address before publishing.

## About This Project

This website was created as part of my IT studies to establish a professional online presence. It is designed to be:

- **Professional** — clean, consistent design with a clear structure
- **Responsive** — works on desktop, tablet, and mobile devices
- **Accessible** — semantic HTML, descriptive alt text, and keyboard-friendly navigation
- **Search-friendly** — basic SEO practices applied, including meaningful page titles, meta descriptions, and descriptive link text

## Pages


| Page            | Purpose                                                                      |
| --------------- | ---------------------------------------------------------------------------- |
| **Home**        | Professional introduction, career interests, and profile photo               |
| **About Me**    | Why I chose IT, my career goals, and the skills I am developing              |
| **My Projects** | Selected projects with descriptions, technologies, and repository links      |
